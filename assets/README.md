# Entry assets

이 디렉터리에는 Entry 프로젝트 JSON이 참조하는 실제 이미지, 썸네일, 사운드 파일을 둡니다.

Entry 파일 ID의 앞 4글자를 기준으로 2글자씩 디렉터리를 만듭니다.

```text
assets/
└── ab/
    └── cd/
        ├── image/abcd1234.png
        ├── thumb/abcd1234.png
        └── sound/abcd1234.mp3
```

`abcd1234`의 에셋 경로는 `ab/cd/` 아래에 있어야 합니다. 파일명과 확장자는 프로젝트 JSON의 `fileurl` 또는 `thumbUrl` 값과 일치해야 합니다.

`entscript build`는 프로젝트 디렉터리의 `assets/`를, 직접 컴파일은 현재 작업 디렉터리의 `assets/`를 사용합니다. 프로젝트 JSON에서 실제로 참조하는 파일만 `.ent` 패키지의 `temp/` 아래로 복사됩니다. 참조 파일이 없거나 참조 경로 중간에 심볼릭 링크가 있으면 빌드가 실패합니다. 사용되지 않는 파일과 이 디렉터리 구조를 따르지 않는 파일은 패키지에 포함되지 않습니다.

`README.md` 같은 설명 파일이나 임의의 썸네일 파일은 패키지에 포함되지 않습니다. 심볼릭 링크도 포함되지 않습니다.
